# Island Events Platform: Production Deployment & Operations Architecture

## 1. Storage Configuration (Multi-Tenant Object Storage)

### Architecture & Provider
The platform uses S3-compatible cloud object storage (Cloudflare R2 or AWS S3) configured for secure multi-tenant isolation, public flyer CDN delivery, and protected private receipts.

```
storage-bucket/
├── public/
│   └── tenants/{organizer_id}/flyers/
│       └── {sha256_hash}_{timestamp}.webp
└── private/
    └── tenants/{organizer_id}/
        ├── receipts/
        │   └── {order_number}_{timestamp}.pdf
        └── exports/
            └── financial_report_{date}.csv
```

### Storage Drivers (`config/filesystems.php`)
```php
'disks' => [
    's3_flyers' => [
        'driver' => 's3',
        'key' => env('AWS_ACCESS_KEY_ID'),
        'secret' => env('AWS_SECRET_ACCESS_KEY'),
        'region' => env('AWS_DEFAULT_REGION', 'auto'),
        'bucket' => env('AWS_FLYERS_BUCKET'),
        'url' => env('AWS_FLYERS_CDN_URL'), // Cloudflare Custom Domain CDN
        'endpoint' => env('AWS_ENDPOINT'), // Cloudflare R2 endpoint
        'visibility' => 'public',
        'throw' => true,
    ],
    's3_private' => [
        'driver' => 's3',
        'key' => env('AWS_ACCESS_KEY_ID'),
        'secret' => env('AWS_SECRET_ACCESS_KEY'),
        'region' => env('AWS_DEFAULT_REGION', 'auto'),
        'bucket' => env('AWS_PRIVATE_BUCKET'),
        'visibility' => 'private',
        'throw' => true,
    ],
],
```

### Access Controls & Signed URLs
- **Flyers**: Delivered via global CDN edge with WebP optimization, cached for 30 days (`Cache-Control: public, max-age=2592000`).
- **Receipts & Exports**: Stored in the private bucket. Accessed exclusively through short-lived signed URLs (TTL: 15 minutes) generated by `Storage::disk('s3_private')->temporaryUrl($path, now()->addMinutes(15))`.
- **CORS Configuration**: Allowed origins restricted to production domains (`https://islandevents.app`, `https://*.islandevents.app`) with `GET`, `HEAD` methods.

## 2. Automated Backups & Disaster Recovery

### RPO & RTO Targets
- **Recovery Point Objective (RPO)**: < 1 minute (Continuous WAL Archiving).
- **Recovery Time Objective (RTO)**: < 15 minutes (Automated restore scripts).

### PostgreSQL WAL Archiving & Point-In-Time Recovery (PITR)
- **Tool**: `pgBackRest` or `WAL-G` streaming WAL segments continuously to encrypted off-site S3 storage.
- **Base Backups**: Automated daily full snapshots at 02:00 AM UTC with delta incrementals every 4 hours.

```ini
# /etc/pgbackrest/pgbackrest.conf
[island_events]
pg1-path=/var/lib/postgresql/16/main
repo1-type=s3
repo1-s3-bucket=island-events-db-backups-secure
repo1-s3-endpoint=s3.us-east-1.amazonaws.com
repo1-s3-region=us-east-1
repo1-s3-key=ENV[BACKUP_S3_KEY]
repo1-s3-key-secret=ENV[BACKUP_S3_SECRET]
repo1-cipher-type=aes-256-cbc
repo1-cipher-pass=ENV[BACKUP_ENCRYPTION_PASSPHRASE]
repo1-retention-full=30
repo1-retention-diff=7
```

### Logical Backup Schedule & Retention
- Daily encrypted logical dumps via Laravel Backup (`spatie/laravel-backup`):
  - Database + Storage metadata bundled, encrypted with GPG public key, and transmitted to a secondary backup cloud provider (Wasabi / Backblaze B2) to eliminate single-cloud vendor risk.
  - S3 Object Lock enabled in Compliance Mode for 90 days to prevent ransomware tampering.
- **Weekly Automated Restore Drill**: A sandbox database is spun up every Sunday at 04:00 AM UTC, restores the latest backup, runs test queries, and alerts on Slack upon verified data integrity.

## 3. HTTPS, TLS & Edge Security

### Ingress & SSL Configuration
- **Edge Layer**: Cloudflare Enterprise / Business with Full (Strict) SSL and Automated Edge TLS 1.3 termination.
- **Origin Layer**: NGINX with automated Let's Encrypt certificates managed via `certbot` renewal cron.

```nginx
# /etc/nginx/sites-available/islandevents.conf
server {
    listen 80;
    listen [::]:80;
    server_name islandevents.app www.islandevents.app;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name islandevents.app www.islandevents.app;

    ssl_certificate /etc/letsencrypt/live/islandevents.app/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/islandevents.app/privkey.pem;
    ssl_session_timeout 1d;
    ssl_session_cache shared:SSL:50m;
    ssl_session_tickets off;

    # Modern TLS configuration
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384:DHE-RSA-AES128-GCM-SHA256:DHE-RSA-AES256-GCM-SHA384';
    ssl_prefer_server_ciphers off;

    # Security Headers
    add_header Strict-Transport-Security "max-age=63072000; includeSubDomains; preload" always;
    add_header X-Frame-Options "DENY" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
    add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com; img-src 'self' data: https: blob:; connect-src 'self' https:;" always;

    root /var/www/islandevents/current/public;
    index index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.4-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_buffers 16 16k;
        fastcgi_buffer_size 32k;
    }
}
```

## 4. Queue Workers & Asynchronous Processing

### Architecture & Workload Segregation
The platform uses Redis 7 as the high-throughput queue broker, orchestrated through Laravel Horizon and system-level `supervisord` daemons.

### Dedicated Queues
1. `notifications-urgent`: Instant ticket issuance SMS/Email, cash receipts, and payment verification alerts. (Max wait: 3s).
2. `notifications-bulk`: 24-hour event reminders and pickup notices. (Max wait: 60s).
3. `orders-processing`: Inventory decrement reservations and reporting rollups.
4. `default`: General asynchronous tasks and cache warmups.

### Supervisord Configuration (`/etc/supervisor/conf.d/island-worker.conf`)
```ini
[program:island-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/islandevents/current/artisan horizon
autostart=true
autorestart=true
user=www-data
numprocs=1
redirect_stderr=true
stdout_logfile=/var/log/supervisor/island-horizon.log
stopwaitsecs=3600
killasgroup=true
stopasgroup=true
```

### Horizon Configuration (`config/horizon.php`)
```php
'environments' => [
    'production' => [
        'supervisor-urgent' => [
            'connection' => 'redis',
            'queue' => ['notifications-urgent', 'orders-processing'],
            'balance' => 'auto',
            'autoScalingStrategy' => 'time',
            'minProcesses' => 4,
            'maxProcesses' => 16,
            'memory' => 512,
            'tries' => 3,
            'timeout' => 60,
        ],
        'supervisor-bulk' => [
            'connection' => 'redis',
            'queue' => ['notifications-bulk', 'default'],
            'balance' => 'simple',
            'processes' => 2,
            'memory' => 256,
            'tries' => 3,
            'timeout' => 120,
        ],
    ],
],
```

## 5. Scheduler Configuration & Crontab

### System Crontab
```bash
# Add to crontab of www-data user (crontab -u www-data -e)
* * * * * cd /var/www/islandevents/current && php artisan schedule:run >> /dev/null 2>&1
```

### Scheduled Console Kernel (`routes/console.php` / `app/Console/Kernel.php`)
```php
// Enforce advance ordering cutoff times every minute
Schedule::command('events:enforce-cutoffs')
    ->everyMinute()
    ->withoutOverlapping()
    ->runInBackground();

// Dispatch 24-hour and 4-hour event approaching notifications
Schedule::command('notifications:dispatch-reminders')
    ->hourly()
    ->withoutOverlapping();

// Daily database backup verification & off-site sync
Schedule::command('backup:clean')->dailyAt('01:00');
Schedule::command('backup:run')->dailyAt('02:00');

// Heartbeat healthcheck ping (Healthchecks.io)
Schedule::call(function () {
    Http::get(config('services.healthcheck.scheduler_url'));
})->everyFiveMinutes();
```

## 6. Logging Architecture & Data Protection

### Structured JSON Logging (`config/logging.php`)
Logs are formatted in structured JSON via Monolog to enable indexed querying in Datadog / Grafana Loki / CloudWatch.

```php
'channels' => [
    'daily' => [
        'driver' => 'daily',
        'path' => storage_path('logs/laravel.log'),
        'level' => env('LOG_LEVEL', 'info'),
        'days' => 14,
        'replace_placeholders' => true,
    ],
    'structured_json' => [
        'driver' => 'monolog',
        'handler' => Monolog\Handler\StreamHandler::class,
        'formatter' => Monolog\Formatter\JsonFormatter::class,
        'with' => [
            'stream' => storage_path('logs/structured.json'),
        ],
    ],
],
```

### Context Enrichment & PII Redaction
- Every log entry automatically injects:
  - `tenant_id`
  - `user_id` & `role`
  - `request_id` (UUID from X-Request-ID header)
  - `ip_address`
- **Masking Rules**: Bank account digits, credit card numbers, passwords, auth tokens, and customer street addresses are filtered via `Log::formatters()` before writing to disk.

## 8. Secrets Management & Environment Security

### Multi-Tier Secrets Pipeline
1. **Source Code Cleanliness**: Zero `.env` files or credentials in Git. Automated pre-commit hook runs `trufflehog` and `git-secrets`.
2. **Encrypted Environment Files**: Production `.env` is encrypted using Laravel native AES-256 cipher:
   ```bash
   # On build server
   php artisan env:encrypt --env=production --key=base64:SERVER_SECRET_KEY
   # On target server
   php artisan env:decrypt --env=production --key=base64:SERVER_SECRET_KEY
   ```
3. **OS File Permissions**:
   ```bash
   chmod 600 /var/www/islandevents/current/.env
   chown www-data:www-data /var/www/islandevents/current/.env
   ```
4. **Cloud Secrets Integration**: AWS Secrets Manager / Doppler dynamically injects third-party API keys (Twilio auth token, Mailgun API key, Stripe secret keys) into memory without storing plain text on disk.

## 9. Zero-Downtime Database Migrations Workflow

### The Expand & Contract Pattern
To prevent breaking active web workers during schema updates, all database changes adhere to the two-phase migration standard:

```
Phase 1 (Expand):
- Add new columns as NULLABLE or with sensible DEFAULT.
- Deploy code that writes to both old and new columns.
- Backfill historical data in background job.

Phase 2 (Contract):
- Deploy code reading only from the new columns.
- Drop or rename legacy columns in a subsequent release.
```

### Deployment Migration Command
```bash
# Executed during release step with isolated advisory locks
php artisan migrate --force --isolated
```

## 10. Atomic Deployment & Instant Rollback Procedures

### Atomic Symlink Release Directory Structure
```
/var/www/islandevents/
├── current -> /var/www/islandevents/releases/20261128_104500
├── shared/
│   ├── .env
│   └── storage/
│       ├── app/
│       ├── framework/
│       └── logs/
└── releases/
    ├── 20261128_091500 (Previous stable release)
    └── 20261128_104500 (Active release)
```

### Deployment Automation Script (`deploy.sh`)
```bash
#!/usr/bin/env bash
set -e

RELEASE_DIR="/var/www/islandevents/releases/$(date +%Y%m%d_%H%M%S)"
SHARED_DIR="/var/www/islandevents/shared"
CURRENT_DIR="/var/www/islandevents/current"

echo "Deploying release to ${RELEASE_DIR}..."

# 1. Clone & Build
git clone --depth 1 -b main git@github.com:islandevents/events-app.git "${RELEASE_DIR}"
cd "${RELEASE_DIR}"

# 2. Link shared storage and .env
ln -s "${SHARED_DIR}/.env" "${RELEASE_DIR}/.env"
rm -rf "${RELEASE_DIR}/storage"
ln -s "${SHARED_DIR}/storage" "${RELEASE_DIR}/storage"

# 3. Install dependencies & optimize
composer install --no-dev --prefer-dist --optimize-autoloader --no-interaction
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache

# 4. Migrate database safely
php artisan migrate --force --isolated

# 5. Atomic Symlink Switch
ln -sfn "${RELEASE_DIR}" "${CURRENT_DIR}"

# 6. Reload services
sudo systemctl reload php8.4-fpm
php artisan horizon:terminate
sudo supervisorctl restart island-worker:*

echo "Deployment completed successfully!"
```

### Emergency Rollback Playbook (Sub-30-Second Recovery)
If critical telemetry fails or a regression is detected:

```bash
#!/usr/bin/env bash
# rollback.sh
set -e

CURRENT_DIR="/var/www/islandevents/current"
PREV_RELEASE=$(ls -dt /var/www/islandevents/releases/* | sed -n '2p')

if [ -z "$PREV_RELEASE" ]; then
    echo "ERROR: No previous release directory found!"
    exit 1
fi

echo "Rolling back to ${PREV_RELEASE}..."

# 1. Atomic switch back to previous release
ln -sfn "${PREV_RELEASE}" "${CURRENT_DIR}"

# 2. Roll back last database migration if applicable
cd "${CURRENT_DIR}"
php artisan migrate:rollback --step=1 --force

# 3. Reload PHP-FPM and Queue Workers
sudo systemctl reload php8.4-fpm
php artisan horizon:terminate
sudo supervisorctl restart island-worker:*

echo "Rollback successfully completed!"
```
